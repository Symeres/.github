# Symeres/.github

Default issue forms (Task, Feature, Bug) and the pull request template for every Symeres repository that doesn't have
its own. Issues created from these forms get their issue type and are added to the
[planning](https://github.com/orgs/Symeres/projects/7) board.

GitHub only uses defaults from a public `.github` repository, so keep everything here generic: no client names,
internal URLs or other confidential details.
